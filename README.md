# 🛍️ WhatBytes Frontend Assignment

A responsive e-commerce application built with **Next.js (App Router)** and **Tailwind CSS** as part of the WhatBytes Frontend Developer Internship Assignment.

## 🚀 Live Demo

**Live URL:**  
https://whatbytes-assignment-puce.vercel.app/

## 📂 GitHub Repository

**Repository:**  
https://github.com/helloayushbaliyan/WhatbytesAssignment

## ✨ Features

- Product listing
- Product detail page
- Shopping cart
- Search products
- Category & price filters
- Dynamic routing
- Redux Toolkit for cart state
- Cart persistence with Local Storage
- Fully responsive design

## 🛠️ Tech Stack

- Next.js (App Router)
- React.js
- Tailwind CSS
- Redux Toolkit
- Lucide React
- Fake Store API

## 📦 Getting Started

```bash
npm install
npm run dev
```

Then open:

```
http://localhost:3000
```
